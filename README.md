# 🍓 おやつキャッチ 🍓

おそらから ふってくる おやつを カゴで キャッチする、かわいいミニゲームです。

## あそびかた

1. `index.html` を ブラウザで ひらくだけ！（インストール不要・ファイル1つだけ）
2. 「あそぶ！」を おしてスタート
3. ゆびや マウスで カゴを よこに うごかす（パソコンは ← → キーでもOK）
4. 🍓🍰🍩 などの おやつを とると **+10てん**、⭐ は **+50てん**！
5. 💣 ばくだんを とったり、おやつを おとすと ライフが へるよ（❤️×3）
6. てんすうが あがると レベルアップして、どんどん はやくなる！

ベストスコアは ブラウザに じどうで ほぞんされます。

## とくちょう

- 📱 スマホ（タッチ）も 💻 パソコン（マウス・キーボード）も 対応
- 🔊 こうかおんは Web Audio で せいせい（おとファイル不要）
- 📦 外部ライブラリ・ビルド不要、`index.html` 1ファイルで かんけつ

たのしんでね！😊
