# ☆†ゆめかわMoon†☆

平成16年(2004年)ごろの女子中学生が運営していた個人ホームページの再現サイトです。

## 見かた

`index.html` をブラウザで開くだけ！ビルド不要、依存ゼロ、純度100%の平成HTMLです。

```
python3 -m http.server 8000
# → http://localhost:8000/
```

## 再現ポイント

- マウスカーソルについてくるキラキラ☆
- `<marquee>` と点滅テキスト（blinkタグ亡き今、CSSで供養）
- 7桁アクセスカウンター＆キリ番アラート（77777を踏むとイラストリクエスト権）
- 星空タイル背景・虹色グラデ文字・88×31バナー
- 「無断転載禁止」「直リン禁止」「踏み逃げ厳禁」の三大お約束
- 推奨環境：IE6.0／解像度800×600（嘘です。最近のブラウザで見てね）
